### Fase 2: Formar la Red Thread e Iniciar Servicios

#### 1. Limpieza inicial (Ambos en su monitor serie):
* **TÚ (Placa C) y TU COMPAÑERO (Placa S):**
  ```bash
  ot factoryreset
  ```[cite: 1]

#### 2. Crear la red (TÚ primero en Placa C):
```bash
ot dataset init new
ot dataset commit active
ot ifconfig up
ot thread start
ot dataset active -x
```[cite: 1]
> 📌 **Paso clave:** Copia el texto hexadecimal que te imprime `ot dataset active -x` y envíaselo a tu compañero[cite: 1].

#### 3. Unir la placa a la red (TU COMPAÑERO en Placa S):
```bash
ot dataset set active <CADENA_HEX_DE_C>
ot ifconfig up
ot thread start
```[cite: 1]

#### 4. Obtención de IP e inicio de CoAP:
* **TÚ (Placa C):**
  ```bash
  ot coap start
  ```[cite: 1]
  *(⚠️ **Atención:** Tu compañero **NUNCA** debe ejecutar `ot coap start` en S, para no deshabilitar el puerto 5683 del servidor CoAP de la válvula)*[cite: 1].

* **TU COMPAÑERO (Placa S):**
  ```bash
  ot ipaddr mleid
  ```[cite: 1]
  > 📌 **Paso clave:** Tu compañero debe darte la dirección IPv6 que imprime este comando (ejemplo: `fdde:ad00:beef:0:6a1b:3c4d:9e2f:1a07`)[cite: 1].

---

### Fase 3: Pruebas de Enlace Ascendente (Uplink - Lectura e Inspección)

* **TÚ (Placa C):**
  ```bash
  # 1. Lectura puntual de temperatura (GET)
  ot coap get <S-mleid> env/temp

  # 2. Suscripción automática durante 5 minutos (Observe)
  ot coap observe <S-mleid> env/temp

  # 3. Cancelar la suscripción pasados los 5 minutos
  ot coap cancel
  ```[cite: 1]

* **TU COMPAÑERO (Placa S):** Solo debe estar atento a su consola para registrar cuántas notificaciones se enviaron por umbral (*threshold*) y por *heartbeat* para llenar la tabla del reporte[cite: 1].

---

### Fase 4: Pruebas de Enlace Descendente (Downlink - Control de Válvula)

* **TÚ (Placa C):**
  ```bash
  # 1. Abrir la válvula (LED blanco en S)
  ot coap put <S-mleid> act/valve con 1

  # 2. Consultar el estado de la válvula
  ot coap get <S-mleid> act/valve

  # 3. Cerrar la válvula
  ot coap put <S-mleid> act/valve con 0

  # 4. Probar Idempotencia (enviar dos veces seguidas "con 1")
  ot coap put <S-mleid> act/valve con 1
  ot coap put <S-mleid> act/valve con 1

  # 5. Enviar mensaje malformado (debe dar error 4.00 en la consola de S)
  ot coap put <S-mleid> act/valve con 7
  ```[cite: 1]

#### Prueba de pérdida de red (CON vs NON):
1. **TU COMPAÑERO (Placa S):** Desconecta S de la red ejecutando:
   ```bash
   ot thread stop
   ```[cite: 1]
2. **TÚ (Placa C):**
   ```bash
   # Envía comando confirmable y toma el tiempo con cronómetro hasta ver 'ResponseTimeout' (error 28):
   ot coap put <S-mleid> act/valve con 1

   # Prueba con mensaje no confirmable (NON) y observa que falla en silencio:
   ot coap put <S-mleid> act/valve non-con 1
   ```[cite: 1]
3. **TU COMPAÑERO (Placa S):** Vuelve a conectar S a la red:
   ```bash
   ot thread start
   ```[cite: 1]

---

### Fase 5: Válvula Durmiente (Sleepy End Device - SED)

#### 1. Volver el Nodo S un dispositivo durmiente:
* **TU COMPAÑERO (Placa S):**
  ```bash
  ot mode -
  ot pollperiod 1000
  ot state
  ```[cite: 1]
  *(Debe verificar que la placa imprima `child` y el LED pase a color amarillo)*[cite: 1].

#### 2. Medición de latencias con Ping:
* **TU COMPAÑERO (Placa S):** Irá cambiando el periodo de sondeo con `ot pollperiod 1000`, `ot pollperiod 5000` y `ot pollperiod 15000`[cite: 1].
* **TÚ (Placa C):** En cada cambio de periodo que haga tu compañero, ejecuta los pings para medir el RTT:
  ```bash
  ot ping <S-mleid> 16 10 1.3 64 40
  ```[cite: 1]

#### 3. Verificación de duplicados por retransmisión:
* **TU COMPAÑERO (Placa S):** Configura el sondeo en 5 segundos:
  ```bash
  ot pollperiod 5000
  ```[cite: 1]
* **TÚ (Placa C):** Envía el comando de abrir la válvula:
  ```bash
  ot coap put <S-mleid> act/valve con 1
  ```[cite: 1]
  *(Observen cómo en la consola de S el comando llega 2 veces debido a que la primera retransmisión de CoAP en C ocurre antes de que S despierte a consultar sus mensajes)*[cite: 1, 2].

#### 4. Restauración del nodo S al finalizar:
* **TU COMPAÑERO (Placa S):**
  ```bash
  ot mode rdn
  ot pollperiod 0
  ```[cite: 1]
